# Fontes

O site espera os arquivos das fontes oficiais do Felipe nesta pasta:

- `Melodrame-Regular.woff2` — headlines
- `AeonikPro-Regular.woff2` — texto de apoio (peso 400)
- `AeonikPro-Medium.woff2` — texto de apoio (peso 500)

Sem esses arquivos, o site usa fallback automático (serif do sistema no
lugar de Melodrame, sans-serif no lugar de Aeonik Pro) — funciona, mas
não é a fonte real. Assim que o Felipe mandar os arquivos `.woff2`,
salvar aqui com esses nomes exatos que o site já pega sem mexer no CSS.
